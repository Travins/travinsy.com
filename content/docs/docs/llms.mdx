## llms.txt

站点按 [llms.txt](https://llmstxt.org) 约定提供两个纯文本入口：

- [`/llms.txt`](https://travinsy.com/llms.txt)：站点简介、安装方式、组件清单与文档链接。适合当作索引喂给模型。
- [`/llms-full.txt`](https://travinsy.com/llms-full.txt)：全部文档与博客的 MDX 原文。适合一次性放进上下文。

两个文件都在构建时生成，内容与页面保持一致。

## 在 AI 编辑器中使用

最简单的方式：让 Agent 先读 `https://travinsy.com/llms.txt`，它会找到组件清单和每个条目的 JSON 地址，然后按[安装](/docs/installation/)里的命令安装。

向 Agent 提需求时，建议明确写出：

- 使用 travinsy 的哪个条目，例如「用 `@travinsy/grid-layout` 搭页面骨架」。
- 颜色只用主题变量，不要硬编码。
- 安装后源码属于项目，可以按需修改。

## shadcn MCP

shadcn 官方提供 MCP 服务，可以让 AI 编辑器直接检索和安装 Registry 里的条目。先在 `components.json` 里配置好 `@travinsy` 命名空间（见 [Registry 与命名空间](/docs/registry/)），然后初始化 MCP：

```bash title="终端"
pnpm dlx shadcn@latest mcp init --client claude
```

`--client` 可选 `claude`、`cursor`、`vscode`、`codex` 等。也可以手动写配置，例如 Claude Code 的 `.mcp.json`：

```json title=".mcp.json"
{
  "mcpServers": {
    "shadcn": {
      "command": "npx",
      "args": ["shadcn@latest", "mcp"]
    }
  }
}
```

配置完成后，可以直接这样对 Agent 说：

- 「列出 @travinsy 里所有组件」
- 「把 @travinsy/auth-01 加到项目里」

## 变量体系

所有组件只使用 shadcn 的语义变量：`background`、`foreground`、`muted-foreground`、`primary`、`border` 等，不写死任何颜色。换一套变量，整站颜色就随之改变。

线条网格额外引入一个变量 `--edge`，由前景色按比例混合得到，用于所有线条和分隔带：

```css title="globals.css"
:root {
  --edge: color-mix(in oklab, var(--foreground) 10%, transparent);
}

.dark {
  --edge: color-mix(in oklab, var(--foreground) 12%, transparent);
}
```

因为 `--edge` 跟随 `foreground` 计算，切换任何颜色主题后线条都会自动适配。安装 `grid-layout` 时 CLI 会一并写入它。

## 亮暗模式

亮暗模式通过 `html` 上的 `.dark` class 切换，本站使用 `next-themes` 管理。它和颜色主题互不干扰：同一个颜色主题有亮、暗两组变量。

## 颜色主题

本站提供 14 套颜色主题，色值取自 Tailwind CSS v4 默认调色板（oklch），可以在[颜色主题](/themes/)页面实时预览，切换主题与亮暗模式，并复制 CSS。主题名统一按「中文 · English」显示，英文名就是 Tailwind 的色名，也是安装时用的 id。

颜色主题通过 `html` 上的 `data-theme` 属性启用。

### 中性基底 · Neutrals

三个灰族决定整套界面灰阶的色偏：背景、卡片、`muted`、边框、次要文字和 `primary` 都取自同一个灰族，选择器里用「浅 / 中 / 深」三段色带展示色偏。

| 主题 | id | 亮色 primary | 暗色 primary |
|---|---|---|---|
| 红色 · Red | `red` | red-600 | red-500 |
| 橙色 · Orange | `orange` | orange-600 | orange-600 |
| 琥珀 · Amber | `amber` | amber-600 | amber-600 |
| 青柠 · Lime | `lime` | lime-600 | lime-600 |
| 绿色 · Green | `green` | green-700 | green-600 |
| 青绿 · Teal | `teal` | teal-600 | teal-600 |
| 天蓝 · Sky | `sky` | sky-600 | sky-600 |
| 蓝色 · Blue | `blue` | blue-600 | blue-500 |
| 紫罗兰 · Violet | `violet` | violet-600 | violet-500 |
| 紫红 · Fuchsia | `fuchsia` | fuchsia-600 | fuchsia-500 |
| 粉红 · Pink | `pink` | pink-600（明度下调 0.012） | pink-500 |

- 彩色主题的按钮一律白字：深色字压在饱和色上发脏，统一白字更协调。为此每个主题取能让白字达到 3:1 的档位（按钮文字是 14px 中粗字，按 WCAG AA 大字 / 界面组件标准）；正文和次要文字仍保证 4.5:1，主色作为文字或图形时对背景至少 3:1。
- 红色主题的主色和危险色（`destructive`）本来是同一种红，所以把危险色拉开：亮色改用 red-800，暗色改用 red-300。
- 校验脚本：`pnpm tsx scripts/theme-contrast.ts` 会列出全部主题在亮、暗下的对比度，任何一项不达标就以非零状态退出。

> 之前的 `zinc`、`rose` 已移除。浏览器里保存了这两个 id 的访客会自动回落到默认的 `neutral`，不会报错。

## 安装主题

每套主题都是一个 `registry:theme` 条目，命名为 `theme-<id>`，只写入 CSS 变量：

```bash title="终端"
pnpm dlx shadcn@latest add https://travinsy.com/r/theme-blue.json
```

配置了命名空间时（见 [Registry 与命名空间](/docs/registry/)）：

```bash title="终端"
pnpm dlx shadcn@latest add @travinsy/theme-blue
```

主题不包含 `--radius`，圆角仍由你的 `globals.css` 决定。

## 自定义

直接修改 `globals.css` 里的变量即可。建议只改变量值，不在组件里写具体颜色，这样所有条目都会跟着变化。

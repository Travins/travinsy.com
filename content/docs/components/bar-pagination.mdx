## 用法

```tsx
import { BarPagination } from "@/components/ui/bar-pagination/bar-pagination"

;<BarPagination defaultPage={1} pageCount={7} />
```

底层复用官方 Pagination、PaginationContent、PaginationItem、PaginationLink，补上每页条数、跳页、窄屏布局和方条外观。它用于浏览数据，因此归入数据展示组。小于 30rem 的容器只显示上一页、当前页 / 总页数、下一页。getHref 生成真实链接；按钮模式只发出 onPageChange。跳页按回车提交，有限数字夹到有效页范围，空值和非法值忽略。pageSize 由调用方控制，改变时应同步更新 pageCount 和 page。

## 可访问性

导航有可访问名称，页码提供「第 N 页」名称和 aria-current。首尾翻页按钮禁用；跳页和每页条数有可访问名称。按钮键盘聚焦环在格子内部显示。所有内置文案可通过 labels 覆盖。

## 注意事项

pageCount 至少按一页显示，page 超出范围时夹到有效范围。getHref 模式保持浏览器原生链接行为，跳页会导航到生成的地址。

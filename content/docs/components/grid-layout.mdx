## 用法

每个页面使用一个 `GridContainer`，在其中依次排列 `GridSection` 与 `GridSeparator`。相邻行只绘制底线，避免重复描边。

```tsx title="app/page.tsx"
import {
  GridContainer,
  GridSection,
  GridSeparator,
  GridColumns,
} from "@/components/ui/grid-layout/grid-layout"

export default function Page() {
  return (
    <GridContainer>
      <GridSection className="px-4 py-6">个人介绍</GridSection>
      <GridSeparator />
      <GridSection>
        <GridColumns>
          <div className="p-4">项目</div>
          <div className="p-4">文章</div>
        </GridColumns>
      </GridSection>
    </GridContainer>
  )
}
```

`GridSection` 默认只画底部横线；需要给第一行补一条顶部横线时传 `topLine`。

## 示例

### 分隔带纹路

`GridSeparator` 用 `pattern` 切换纹路。页面里的主分隔用默认的 `dots`（点阵）；`ruler`、`hatch`、`grid`、`plus`、`wave` 适合局部强调或区分不同类型的内容。

<ComponentPreview name="grid-separator-patterns-demo" />

### 编号标签

`label` 在分隔带左侧显示一段等宽小字，后接虚线，可以和任意纹路组合；`pattern="none"` 只保留编号和虚线。

<ComponentPreview name="grid-separator-label-demo" />

### 交点十字

`crosshair` 控制容器竖线与横线交点处的「+」：`GridSeparator` 默认关闭，传 `crosshair` 开启；`GridSection` 传 `crosshair` 会在底线两端绘制。也可以直接使用 `GridCrosshair` 原语，放在任何 `position: relative` 的容器的四个角。

### data-slot 与状态

| 组件 | `data-slot` | 其他属性 |
| --- | --- | --- |
| `GridContainer` | `grid-container` | — |
| `GridSection` | `grid-section` | `data-top-line`（`true` / `false`） |
| `GridSeparator` | `grid-separator` | `data-pattern`；内部还有 `grid-separator-pattern`、`grid-separator-label` |
| `GridColumns` | `grid-columns` | — |
| `GridCrosshair` | `grid-crosshair` | `data-position` |

这些 `data-slot` 都可以作为父级选择器的锚点，例如 `[&>[data-slot=grid-section]]:px-4`。

## 可访问性

- 这些组件只提供容器，不添加 `role`，也不改变文档结构：`GridSection` 渲染真正的 `<section>`，`GridContainer`、`GridSeparator`、`GridColumns` 渲染 `<div>`。
- 行是页面骨架，语义需要自己补：给 `GridSection` 加 `aria-label` 或配合 `aria-labelledby` 指向行内标题，读屏才会把这一行念成区域。原生属性会原样透传。
- `GridSeparator` 与 `GridCrosshair` 是纯装饰，自带 `aria-hidden`，不会被读屏朗读，也不进入 Tab 顺序；纹路没有动画。`label` 同样会被一并隐藏，需要读屏识别的章节名请写在行内的标题里。
- 线条与文字的颜色都来自主题变量（`--edge`、`border-edge`），在亮暗模式和 14 个颜色主题下对比度一致，不依赖颜色传达信息。

## 注意事项

### 容器宽度

通过父元素上的 `--grid-width` 变量调整宽度，默认 `48rem`。文档页面使用 `80rem`。`GridColumns` 在窄屏下堆叠，`sm` 起显示两列。

### 主题与工具类

安装命令会注册 `--edge` 变量与 `border-edge` 主题映射，以及以下 Tailwind CSS v4 工具类：两个横线工具类 `screen-line-top`、`screen-line-bottom`；六个分隔带纹理工具类 `pattern-ruler`、`pattern-hatch`、`pattern-dots`、`pattern-grid`、`pattern-plus`、`pattern-wave`（供 GridSeparator 使用）；两个面积底纹 `bg-hatch`、`bg-dots`，可直接铺在任意元素上。线条与纹路的颜色都来自 `--edge` / `--foreground`，随颜色主题和亮暗模式变化。

全宽横线需要页面的 `html` 设置 `overflow-x: clip`；Registry 安装会一并写入该规则。

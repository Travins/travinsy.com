## 用法

父容器需要 `relative`，组件默认绝对定位在它的左上外侧；`lg` 以下自动隐藏，避免挤占窄屏内容。

```tsx title="app/follow-me.tsx"
import { FollowMe } from "@/components/ui/follow-me/follow-me"

export function SocialSection() {
  return (
    <section className="relative px-4 py-4">
      <FollowMe />
      <div className="flex gap-2">…社交链接…</div>
    </section>
  )
}
```

- 文字使用系统自带的手写体（`Bradley Hand`、`Segoe Print`），不加载任何 webfont；两者都缺失时退回 `cursive`。
- 箭头是内联 SVG，`stroke` 取 `currentColor`，所以颜色由 `text-muted-foreground` 决定，跟随亮暗模式与颜色主题。
- `pointer-events-none` 保证它不会抢走点击，`aria-hidden` 让读屏完全忽略它。

## 注意

- 默认样式带 `-left-32`，父容器右侧要留出约 8rem 的空白，否则会被内容区裁掉。
- 只在 `lg` 及以上显示；`className` 里的 `absolute`、`hidden` 这类定位与显示工具类可以直接覆盖，演示就是这样改成静态排列的。
- 组件是纯函数组件，没有 `"use client"`，可以放进服务端组件。

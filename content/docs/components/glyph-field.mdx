## 用法

`GlyphField` 负责背景，子内容使用普通 DOM，居中叠放在画布之上。高度由外框决定，可用 `className="h-screen"` 铺满屏幕，默认最小高度为 18rem。

```tsx title="components/security-field.tsx"
import { GlyphField } from "@/components/ui/glyph-field/glyph-field"

export function SecurityField() {
  return (
    <GlyphField glyphs="hex" tone={["muted", "primary"]} fade="center" paused>
      <h2>安全访问</h2>
      <p>端到端加密 · 零信任</p>
    </GlyphField>
  )
}
```

将 `paused` 设为 `false` 可播放随机闪烁。持续动画旁应提供暂停按钮，页首的演示展示了受控暂停的做法：按钮的状态直接绑定 `paused`。`glyphs` 可以是 `latin`、`binary`、`hex`、`katakana`、`cjk`，也可以直接传入任意字符串。字符按 Unicode 码点拆分，不会截断常见汉字。

## 示例

### 中文字符

外层加 `dark` 让这一块按暗色取色，常用汉字与绿色字符交错排列，`fade="center"` 给标题留出空位。此处使用静帧；移除 `paused` 即可闪烁，仍会尊重系统的减少动态效果设置。

<ComponentPreview name="glyph-field-cjk-demo" />

### 二进制横幅

更矮的容器也能自动铺满。`density` 控制格子占用率，`fontSize` 控制字符尺寸，`fade="none"` 保留完整矩阵，文字放在带底色的块里保证可读。

<ComponentPreview name="glyph-field-binary-demo" />

### 自定义字符集

`glyphs` 接受任意字符串，按 Unicode 码点拆分。`tone` 数组里重复某个值可以提高它出现的频率，示例让紫色占一半。

## API

### GlyphField

<PropsTable name="glyph-field" component="GlyphField" />

- `tone` 支持 `primary / foreground / muted / destructive / blue / green / amber / rose / violet / cyan`、CSS 变量表达式或数组；数组可重复某个色调以提高它的出现频率。
- `density` 是 0–1 的占用率；`fontSize` 最小 8px；`speed` 是每个逻辑帧的更新比例（0–1，默认 0.04），逻辑帧率为 20fps，0 表示静止。
- `fade="edges"` 四周淡出，`center` 让中心留白，`none` 保留完整矩阵。遮罩只作用于背景。
- 空字符集不绘制字符；空色调数组回落到 `muted`。

## 可访问性

- 字符背景默认从读屏隐藏，传 `label` 后仅背景获得图片语义；子内容始终可被读取，也可以放置链接或按钮。
- 装饰字符不进入实时播报区域，避免不断打断读屏。
- `paused`、离屏、浏览器标签页不可见或系统减少动态效果开启时停止动画。减少动态效果模式保留静态一帧。

## 注意事项

- 服务端和无 JavaScript 环境输出同尺寸的淡底色占位与完整子内容，画布就绪不会改变布局。
- 使用 ResizeObserver 跟随容器大小，设备像素比最高 2，单个画布最多 30000 个格子。
- 只重绘发生变化的格子；颜色在主题、亮暗模式或祖先局部主题改变时重新解析。修改外部样式表时可通过更新 `tone` 触发重新取色。
- 色调由 `flow-diagram` 的 `--flow-*` 变量提供，安装时一并带入。

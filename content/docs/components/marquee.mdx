## 用法

每组内容至少铺满容器，复制组首尾相接。动画由 CSS 驱动，`ResizeObserver` 仅测量一组内容的尺寸，按 `尺寸 / speed` 换算时长。

```tsx title="components/marquee-example.tsx"
import { Marquee, MarqueeItem } from "@/components/ui/marquee/marquee"

export function MarqueeExample() {
  return (
    <Marquee speed={48} gap={32} label="设计关键词">
      <MarqueeItem>线条网格</MarqueeItem>
      <MarqueeItem>LINE GRID</MarqueeItem>
      <MarqueeItem>组件库</MarqueeItem>
    </Marquee>
  )
}
```

页首的预览是两条反向滚动的丝带：`rotate` 把整条带子旋转 ±9°，交叉成 X 形。旋转带应放在带 `overflow-hidden` 的外层，并加宽到覆盖两端。

## API

### Marquee

<PropsTable name="marquee" component="Marquee" />

- `direction` 默认 `left`，支持 `left / right / up / down`；`reverse` 在当前方向上反转。
- `speed` 默认 `48`，单位为像素/秒，最小按 `1` 处理。间距与字体变化都会重新测量，因此长短内容的移动速度一致。
- `repeat` 默认 `3`，表示内容组总数，限制在 `2–20`。它不改变一组内容的移动速度。
- `gap` 默认 `32`，单位为像素；负值按 `0` 处理。组尾保留相同间距，接缝不会多一格或少一格。
- `fade` 默认开启，沿滚动方向对两端做渐隐。
- `rotate` 默认 `0`，单位为度。旋转带应放在带 `overflow-hidden` 的外层，并适当加宽以覆盖两端。
- `pauseOnHover` 默认开启；`paused` 可直接暂停。键盘焦点进入容器时始终暂停。
- `label` 默认“跑马灯”，可覆盖区域的朗读说明。

### MarqueeItem

<PropsTable name="marquee" component="MarqueeItem" />

项目默认不收缩、不换行，支持自定义布局和样式。纵向多行内容可用 `whitespace-normal`。

## 可访问性

- 只有第一组内容参与朗读；复制组使用 `aria-hidden` 与 `inert`，不进入焦点顺序。
- 区域可通过 Tab 聚焦，聚焦后暂停，便于阅读。
- 开启“减少动态效果”后取消动画、旋转与遮罩，只保留原始内容；可用键盘或触控滚动查看，纵向列表同样可滚动。
- 对会持续移动的正文，提供邻近的暂停控件并绑定 `paused`。装饰性丝带可在外层使用 `aria-hidden`，同时设置 `tabIndex={-1}`。

## 注意事项

- 无 JS 时仍运行 CSS 动画，使用每组 `30s` 的回退时长。精确的 px/s 换算需要客户端测量，不能从服务端获知任意字体与内容的实际宽度。
- 请使用非交互展示内容，避免在复制组内放置表单、带固定 `id` 的元素或有副作用的组件。复制体虽然不可交互，仍会挂载。
- 组件自身不设置色彩或背景；通过主题 token 组合带子和胶囊。

## 用法

`ChartCard` 是外壳，分 `Header` / `Content` / `Footer` 三个区域，区域之间用细线隔开；图表放在 `Content` 里。

```tsx title="app/traffic.tsx"
import {
  ChartCard,
  ChartCardContent,
  ChartCardDescription,
  ChartCardHeader,
  ChartCardTitle,
  ChartSeries,
} from "@/components/ui/chart-card/chart-card"

const data = [
  { day: "2026-02-01", docs: 6200, blog: 4800 },
  { day: "2026-02-02", docs: 6900, blog: 5100 },
  // …
]

export function Traffic() {
  return (
    <ChartCard>
      <ChartCardHeader>
        <div>
          <ChartCardTitle>站点流量</ChartCardTitle>
          <ChartCardDescription>每日页面访问量</ChartCardDescription>
        </div>
      </ChartCardHeader>
      <ChartCardContent>
        <ChartSeries
          data={data}
          xKey="day"
          series={[
            { key: "docs", label: "文档" },
            { key: "blog", label: "博客" },
          ]}
        />
      </ChartCardContent>
    </ChartCard>
  )
}
```

| 组件 | 用途 |
| --- | --- |
| `ChartCard` + `Header` / `Title` / `Description` / `Action` / `Content` / `Footer` | 卡片布局 |
| `ChartMetrics` + `ChartMetric` | 竖线隔开的指标行 |
| `ChartTable` | 图表下方的明细表，首列带与序列同色的竖条 |
| `ChartGauge` | 刻度式环形仪表 |
| `ChartSeries` | 折线 / 柱 / 面积，支持堆叠与正负对比 |
| `ChartRanking` | 横向排名条 + 图例格 |
| `ChartLegendList` / `ChartLegendGrid` | 行内图例、图例格 |

页面顶部的预览把几个部件拼在了一张卡片里：左边 `ChartGauge` 显示目标进度，右边 `ChartSeries` 画两条面积序列，头部的 `ChartMetrics` 用同色圆点与序列对应。

## 示例

### 刻度式环形仪表

`ChartGauge` 由一圈细刻度组成，按值依次点亮：点亮的刻度由淡到浓，最后一格最亮最长，像指针停在当前值上。`ticks` 控制刻度数，`arc` 控制总角度（默认 270° 下方留口，360 为整圈），`fade={false}` 关掉渐变，`children` 替换中央内容。

<ComponentPreview name="chart-card-gauge-demo" />

### 多序列折线与明细表

`ChartSeries` 默认画折线；序列多于一条时在上方显示图例。图表下方的 `ChartTable` 用 `columns` 和 `rows` 描述明细，行里的 `tone` 对应图表里的序列。

<ComponentPreview name="chart-card-demo" />

### 堆叠柱与指标行

`type="bar"` 加 `stacked` 得到堆叠柱；头部的 `ChartMetrics` 把几个关键指标并排摆在一起。

<ComponentPreview name="chart-card-stacked-demo" />

### 正负对比

`stacked="diverging"` 让正值向上、负值向下堆叠，适合新增与流失、收入与支出这类方向相反的数据：把流失记为负数，两组数据就落在零线两侧，提示框里仍显示各自的数值。

<ComponentPreview name="chart-card-diverging-demo" />

### 排名条

`ChartRanking` 用名次作纵轴，条末标出数值，旁边（窄屏在下方）是带名称的图例格。百分比数据传 `max={100}`，其他数据默认取最大值作满值。

<ComponentPreview name="chart-card-ranking-demo" />

### 配色与坐标轴

序列没有指定 `tone` 时按顺序取默认色板：蓝、琥珀、绿、紫、玫红、青。默认色板里没有主题强调色——强调色会落在其中某一种附近，切到对应的颜色主题时会和那条序列撞色；单条序列想跟随主题时显式写 `tone="primary"`。颜色全部来自主题变量，14 个颜色主题和亮暗模式下都能正确显示。`tone` 也可以是 `chart-1` … `chart-5`、`up` / `down`（涨跌色，随 `convention` 变化）或任意 CSS 颜色。

坐标轴字号 11px，网格只有水平虚线，颜色是线条网格的 `--edge`。日期轴用 `formatDay` 变成「2月14日」或「02/14」，星期轴是单字「一…日」，纵轴整条轴共用一个单位：按数据最大值选「万 / 亿」（`en` 为 K / M / B），所有刻度都换算成它，不会出现 `9000` 与 `1.2万` 混在一起；数据的最大值不到 1 万时刻度都是普通整数。

## 可访问性

- 图表容器是 `role="img"`，名称来自 `label`；悬停提示框读取精确数值。需要让读屏用户拿到数据时，配一张 `ChartTable` 或在文字里写出关键数字。
- `ChartGauge` 是 `role="meter"`，带 `aria-valuenow` 和 `aria-valuemax`；中央的数字是真实文本。
- `ChartTable` 用语义化的 `<table>`，表头 `scope="col"`，窄屏横向滚动而不是挤压。
- 序列靠图例的名称区分，不只靠颜色。
- 开启「减少动态效果」后，recharts 的入场动画关闭，仪表的刻度不再依次淡入；仪表的刻度由服务端直接输出，淡入是纯 CSS，没有脚本也完整显示。

## 注意事项

- 图表由 `ResponsiveContainer` 撑满容器，服务端渲染时先按 320×200 占位，水合后量出真实尺寸；`ChartSeries` 的高度用 `className`（默认 `h-64`）控制。
- 纵轴宽度用 `width="auto"` 按刻度文字自适应，需要和别的图表对齐时给相同的 `yDomain` 与 `yTicks`。
- 涨跌配色约定见 [统计卡片](/components/stat-card#涨跌配色约定)；`ChartCard` 与 `ChartSeries` 也接受 `convention`。

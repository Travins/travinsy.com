这个 AI 助手面板提炼自我的一个企业监控平台项目，保留「在工作区旁边排查问题」的交互，去掉认证、业务接口与监控数据依赖。默认使用离线模拟数据，不需要密钥或服务端。

- **两种布局**：右侧嵌入面板、右下角浮动窗口；聊天记录、输入草稿和滚动位置在切换时保留。
- **可检查的过程**：Trace 展示分析摘要、运行中的工具、成功与失败结果，以及可打开的参考来源。输入与输出可折叠查看。
- **流式演示**：应用监控、vLLM 显存、CI 安装失败三个剧本，其他问题使用通用剧本。所有 reasoning 均为预写的演示摘要，不是真实模型的隐藏思维。
- **对话操作**：复制、点赞/点踩、重新生成、新建对话、停止生成。反馈仅保存在当前页面，不会上报。
- **窄屏适配**：小于 768px 时，两种模式都使用底部 Sheet，带焦点管理和 Escape 关闭；嵌入面板支持用鼠标或触摸拖动、用方向键调整宽度。

## 安装

<InstallCommand name="agent-chat-01" />

会安装 `app/agent/page.tsx` 页面，以及 `components/agent-chat/` 下的组件与数据文件。共享 hook 安装到 `hooks/use-controllable-state.ts`。shadcn 依赖来自官方 registry；npm 依赖为 `ai`、`@ai-sdk/react`、`motion`、`lucide-react`、`class-variance-authority`。实现基于 AI SDK 7 与 React SDK 4。

## 用法

```tsx title="app/workspace/page.tsx"
"use client"

import {
  AgentChatPanel,
  AgentChatProvider,
  AgentChatTrigger,
} from "@/components/agent-chat/agent-chat"

export default function Workspace() {
  return (
    <AgentChatProvider defaultMode="embedded" defaultOpen>
      <div className="flex h-dvh flex-col">
        <header className="p-4">
          <AgentChatTrigger variant="button" />
        </header>
        <div className="flex min-h-0 flex-1">
          <main className="min-w-0 flex-1 overflow-auto p-6">你的工作区</main>
          <AgentChatPanel />
        </div>
        <AgentChatTrigger />
      </div>
    </AgentChatProvider>
  )
}
```

Provider 内只创建一个 `useChat` 实例，也只挂载一个面板。将面板放在与 `main` 同级的 flex 容器中；嵌入时默认宽 400px，调整范围 320–640px，父容器需要有明确高度与 `min-h-0`。

## API

### AgentChatProvider

| 属性              | 类型                       | 默认值 / 说明                          |
| ----------------- | -------------------------- | -------------------------------------- |
| `defaultMode`     | `"embedded" \| "floating"` | `"floating"`                           |
| `defaultOpen`     | `boolean`                  | `false`                                |
| `transport`       | `ChatTransport<UIMessage>` | 内置 mock transport                    |
| `suggestions`     | `string[]`                 | 三个示例问题，传 `[]` 隐藏             |
| `title`           | `string`                   | `"AI 助手"`                            |
| `initialMessages` | `UIMessage[]`              | 可选的初始记录，演示页用它预填一轮对话 |
| `children`        | `ReactNode`                | 工作区内容                             |

`default*` 与 `initialMessages` 只用于初始化。更换会话或 transport 配置时，可通过 Provider 的 React `key` 重新创建实例。会话状态仅在当前 Provider 生命周期内保存，刷新后重置；浮动窗口位置单独保存在 `localStorage`（`travinsy:agent-chat:position`），刷新或切换布局后仍会恢复。读取时以及窗口尺寸变化时，都会把位置约束在视口内。存储不可用时仍可在当前页面移动。

### labels

`labels` 接收 `Partial<AgentChatLabels>`，覆盖 `config.ts` 中 `DEFAULT_LABELS` 的任意几项（面板标题、输入框占位、按钮名称、状态文案等），例如 `labels={{ title: "工程助手", welcome: "今天要解决什么问题？" }}`。`thought` 支持 `{seconds}` 占位符；`moveWindow`（默认 `"移动助手窗口"`）用作浮动窗口拖动手柄的可访问名称；完整键列表见 `config.ts`。

### AgentChatPanel

<PropsTable name="agent-chat-01" component="AgentChatPanel" />

`draggable?: boolean` 默认 `true`，允许桌面浮动模式拖动；传 `false` 禁用指针和键盘移动。小于 768px 的 Sheet 自动禁用拖动。标题栏支持鼠标与触控拖动，操作按钮不会触发拖动；双击标题栏复位到默认右下角。`data-draggable` 表示可移动，拖动期间面板与标题栏设置 `data-dragging="true"`。

### 触发器、建议问题与 Hook

| 导出                  | API                                                                                                            |
| --------------------- | -------------------------------------------------------------------------------------------------------------- |
| `AgentChatPanel`      | `{ className?: string; id?: string; draggable?: boolean }`；关闭时不渲染；桌面嵌入为 `aside`                   |
| `AgentChatTrigger`    | `{ variant?: "fab" \| "button"; className?: string }`；默认 `fab`，只在浮动模式关闭时显示                      |
| `useAgentChat()`      | `{ mode, setMode, toggleMode, open, setOpen }`；必须在 Provider 内调用                                         |
| `AgentChatSuggestion` | `{ question: string; children?: ReactNode; className?: string }`；从外部工作区打开面板并发送问题，生成期间禁用 |
| `AgentChatMode`       | `"embedded" \| "floating"`                                                                                     |

`Enter` 发送，`Shift + Enter` 换行，中文输入法选词时不会误发送。生成中点击「停止」调用 `stop()`；已收到的内容保留，未完成的工具标记为「已停止」。阅读旧消息时不会强制滚动到底部。

## 可访问性

- 标题栏与反馈按钮均有中文可访问名称，输入框有标签。
- 聊天记录通过 `aria-live="polite"` 播报新增内容；按钮暴露 `aria-expanded`、`aria-pressed`，面板通过 `data-mode`、`data-state` 暴露状态。
- `Enter` 发送，`Shift + Enter` 换行；输入法组合期间不会误发。调整面板宽度可用左右方向键。
- 浮动模式下，Tab 聚焦「移动助手窗口」手柄，方向键每次移动 16px，Shift + 方向键移动 64px；Home、Enter 或空格复位到默认右下角。双击标题栏也可复位。移动始终限制在视口内；窄屏或 `draggable={false}` 时不显示手柄。
- 窄屏 Sheet 提供焦点管理、焦点回到触发区域和 Escape 关闭。
- 动效遵循 `prefers-reduced-motion`，来源链接标注新标签页。

### Mock transport 设计

`mock-transport.ts` 按最后一条用户消息匹配正则，构造标准 `UIMessageChunk` 队列。每次 `pull` 只输出一个片段：reasoning → 多个 dynamic tool → source-url → text → finish。延迟定时器受 `AbortSignal` 和流取消控制，不会执行真实命令或请求业务服务；`reconnectToStream` 返回 `null`。

`chat-message.tsx` 同时接受动态工具与 `tool-*` 静态工具消息。Markdown 仅支持段落、列表与行内代码，不执行 HTML；来源 URL 仅允许 HTTP(S)。

### 接入真实后端

客户端只需替换 transport；保持 `useChat` 在 Provider 中：

```tsx title="app/workspace/page.tsx"
"use client"

import { useState } from "react"
import { DefaultChatTransport } from "ai"
import {
  AgentChatPanel,
  AgentChatProvider,
  AgentChatTrigger,
} from "@/components/agent-chat/agent-chat"

export default function Workspace() {
  const [transport] = useState(
    () => new DefaultChatTransport({ api: "/api/chat" }),
  )
  return (
    <AgentChatProvider transport={transport} defaultOpen>
      <main>你的工作区</main>
      <AgentChatPanel />
      <AgentChatTrigger />
    </AgentChatProvider>
  )
}
```

下面的服务端示例应放在支持服务端运行的应用或独立 API 服务中。**本站是纯静态导出，不部署这个 POST Route Handler。** 跨域后端可以给 `api` 配置完整 URL，并在后端配置 CORS。真实应用还需实现认证、输入校验与工具权限控制。

```tsx title="app/api/chat/route.ts（服务端应用示例）"
import {
  convertToModelMessages,
  stepCountIs,
  streamText,
  tool,
  type UIMessage,
} from "ai"
import { z } from "zod"

export async function POST(request: Request) {
  const { messages }: { messages: UIMessage[] } = await request.json()
  const result = streamText({
    // 使用你配置的模型或 AI Gateway；密钥仅在服务端配置。
    model: "openai/gpt-5-mini",
    messages: await convertToModelMessages(messages),
    abortSignal: request.signal,
    stopWhen: stepCountIs(3),
    tools: {
      readMetrics: tool({
        description: "读取授权范围内的监控摘要",
        inputSchema: z.object({ service: z.string() }),
        execute: async ({ service }) => {
          // 替换为带权限检查的真实只读查询。
          return { service, availability: "99.95%", demo: true }
        },
      }),
    },
  })
  return result.toUIMessageStreamResponse({
    originalMessages: messages,
    sendReasoning: true,
    sendSources: true,
  })
}
```

`sendReasoning` 仅在模型提供可公开的 reasoning 内容时才有数据；不支持时可以省略该部分。工具 `input-streaming / input-available` 映射为运行中，`output-available` 映射为完成，`output-error / output-denied` 映射为失败；停止时未结束的调用显示为已停止。模型或检索工具提供的 `source-url` 映射为来源链接，不会自动生成引用。服务端应只发送适合向用户公开的分析摘要与工具输出。

参考：[shadcn Trace](https://ui.shadcn.com/docs/components/aria/trace)、[AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/chatbot)。

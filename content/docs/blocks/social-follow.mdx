## 简介

`SocialFollow` 把一组图标链接排成一行，左侧容器外的空白处（gutter）放一个手写体的 `follow me` 加箭头。装饰只在 `lg` 以上显示，纯装饰，读屏会跳过。

> 预览里能看到手写体，是因为 iframe 宽度够大。窄屏下装饰会自动隐藏。

## 文件结构

```text
components/social-follow/

```

## 用法

```tsx title="app/page.tsx"
import { Mail } from "lucide-react"
import { GitHubMark, XMark } from "@/components/social-follow/brand-icons"
import { SocialFollow } from "@/components/social-follow/social-follow"
import { GridContainer } from "@/components/ui/grid-layout/grid-layout"

export default function Page() {
  return (
    <GridContainer>
      <SocialFollow
        socials={[
          { name: "GitHub", href: "https://github.com/你", icon: <GitHubMark /> },
          { name: "X", href: "https://x.com/你", icon: <XMark /> },
          { name: "邮件", href: "mailto:hi@example.com", icon: <Mail strokeWidth={1.5} /> },
        ]}
      />
    </GridContainer>
  )
}
```

## Props

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `socials` | `{ name: string; href: string; icon: ReactNode }[]` | 链接列表；`name` 同时作为读屏名称和悬停提示 |
| `note` | `string` | 右侧小字，默认「在别处，也在这里」，传空字符串隐藏 |
| `className` | `string` | 追加到外层 `GridSection` |

## 如何自定义

- **换图标**：`icon` 接收任意节点，用 `lucide-react`、自己的 SVG 都可以。品牌图标放在 `brand-icons.tsx`，想加别的平台就往里补。
- **去掉装饰**：删掉 `social-follow.tsx` 里的 `<FollowMe />` 即可，也不再需要 `follow-me` 依赖。
- 所有链接默认 `target="_blank"`，并带上 `rel="noreferrer noopener"`。

个人网站同时承载介绍、作品与技术文档。如果每个区块都有独立背景、圆角和阴影，页面很容易变得嘈杂。本站用线条网格组织页面，用一组连续的边界建立结构。

## 先确定一条阅读轴

首页与博客的内容区宽度是 64rem，文章正文再收窄到约 42rem 保证可读。左右两条竖线限定阅读范围，内容按行向下展开；行末的细横线延伸到屏幕边缘，让窄内容区与整个视口建立联系。

这里的线不是表格边框。它们只需要告诉读者：这一段结束了，下一段从这里开始。因此，相邻两行只画一次底线，避免叠出更粗的接缝。

## 三种分隔，三种关系

普通横线划分同一主题里的内容。点阵分隔带用在主题切换处，例如从个人介绍进入作品。行内需要并列展示时，再用虚线分栏表达较弱的关系。

这些规则收在同一套原语里：

```tsx title="布局示意"
import {
  GridColumns,
  GridContainer,
  GridSection,
  GridSeparator,
} from "@/registry/ui/grid-layout/grid-layout"

export function Example() {
  return (
    <GridContainer>
      <GridSection className="px-4 py-6">个人介绍</GridSection>
      <GridSeparator />
      <GridSection>
        <GridColumns>
          <div className="p-4">组件</div>
          <div className="p-4">文章</div>
        </GridColumns>
      </GridSection>
    </GridContainer>
  )
}
```

`GridContainer` 每页只需要一个。`GridColumns` 在窄屏自然堆叠，虚线也随排列方向变化。页面作者决定内容关系，原语负责把关系画出来。

## 让线退后，让文字站稳

线条使用 `edge` 主题变量，它由前景色混合得到。这样切换亮暗模式或颜色主题时，边界仍然可见，强度也能随背景变化。标题和正文使用前景色，说明文字使用弱化色；强调色只留给少量重点和交互反馈。

日期、标签和编号用等宽字体，帮助读者快速识别元信息。中文正文保持约 1.75 倍行高，标题收紧字距。与其给每段内容增加装饰，不如先检查内边距和段落间距是否一致。

## 从手机宽度检查结构

在 375px 视口中，先看长标题能否自然换行，再检查分栏是否堆叠、代码块是否在自身内部滚动。横线延伸到屏幕边缘不应该带来页面级横向滚动。

最后分别切换亮暗模式和颜色主题。若必须依赖某个固定灰色才能成立，就说明结构和配色还没有真正分开。线条网格的价值，是让相同的内容关系在不同屏幕与主题里都能被读懂。

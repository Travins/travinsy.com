上一版标志是一个带 `>_` 终端提示符的方块，下面接三道 45° 斜撇。外轮廓 18 个顶点，还挖了两个孔。用了几天，越看越嫌它复杂，缩到页头那么小，细节全糊在一起。

可整个标志里最有辨识度的，一直是下面那三道斜撇。

## 一个字，两组三道杠

我想反过来试试：既然三道杠最好认，能不能整个字都用杠来写？

站点叫「易」。这个字上面是「日」，下面是「勿」，有变易、简易、交易三层意思。对写代码的人来说，把复杂的东西变简单，本身就是「易」。

![把「易」拆成上「日」下「勿」，再落到六根斜杠上](/images/blog/logo-design/intent.jpg)

「勿」本来就是几道撇，旧标志里的三道粗杠可以直接留下。「日」是一个扁框，中间一横，数下来也是三道横画，换成三道细杠正好。上下两组，各三道。

## 铅笔和减法

这种几何在屏幕上拖点，很难找到感觉。我做了一张 A4 辅助线稿，一页四格，每格先填好下面三道粗杠：斜线统一 1:2，杠厚 72，杠距 26，方格边长也是 26。打印出来，拿铅笔在上半部分涂各种「日」。

![打印辅助线后，用铅笔涂出来的四种「日」](/images/blog/logo-design/hand-sheet.jpg)

右下那格最老实：一个封闭的框，里面三道杠。另外几格在试杠的长短和起点。涂完两件事很清楚。上面的杠必须比下面细，不然两组粘在一起，分不出上下。杠和杠之间也还能再挤一点。

剩下的就是一样一样往下拿。

![从上一版标志到六根斜杠，一步一步减](/images/blog/logo-design/evolution.jpg)

起点是旧标志里圈出来的那三道斜撇。我把它们挪到下面做「勿」，上面的「日」先画成一个实心块加一个孔。然后把实心块拆成三道细杠，左右各用一根竖条封住，它还是个框。接着拿掉左边的竖条，「日」不再闭合。最后右边的竖条也拿掉，每道杠缝都从右边穿出去。

到这一步，六根杠互不相连，只靠右端切齐连成一个整体，像六道朝右上扫过去的笔画。做减法的标准只有一条：拿掉之后还认得出「易」，那样东西就是多余的。

## 让「看起来对齐」可以检查

手稿只定方向，尺寸得在电脑上定。上组的杠厚和左端位置有好几种都说得过去的组合，我排成一张表，同一个尺寸、同一种配色并排看，顺便看了双色。

![上杠厚度与左端位置的组合，以及双色示意](/images/blog/logo-design/variants.png)

最后选了上杠厚 36、上组左端和下组第三道杠对齐的那一版。

我不想以后每次改动都靠眼睛再确认一遍，就把每一处「看起来对齐」都写成「必须落在这条线上」：

- 外框 416 × 584，所有斜边都是 1:2，每根杠两端竖直切齐
- 下组杠厚 72，左端依次是 0 / 78 / 156
- 上组杠厚 36，左端都在 156，和下组第三道杠对齐
- 所有杠缝都是 26，六根杠右端都切在 x=416

![手工制图：1:2 的斜向辅助线、杠厚与杠缝](/images/blog/logo-design/construction-sketch.jpg)

选 1:2 有个好处：横走 2 个单位正好升 1 个，只要左右端的 x 都是偶数，所有顶点就都是整数，不会冒出 `130.5` 这种坐标。几何交给一个 Python 脚本生成，里面写了三条自检：顶点必须是整数，斜边必须是精确的 1:2，总高必须是 584，有一条不满足就报错。脚本还会输出一张核对图，把每条边和每个尺寸都标出来。

![核对图：红色虚线是每条边，右侧数字是斜线在右边界处的高度，蓝色是杠厚与杠缝](/images/blog/logo-design/construction.png)

成品是六个平行四边形，上下两组各一条路径：

```xml title="logo.svg"
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 416 584">
  <path fill="var(--logo-upper, currentColor)" d="M156 130 416 0 416 36 156 166ZM156 192 416 62 416 98 156 228ZM156 254 416 124 416 160 156 290Z"/>
  <path fill="var(--logo-lower, currentColor)" d="M0 394 416 186 416 258 0 466ZM78 453 416 284 416 356 78 525ZM156 512 416 382 416 454 156 584Z"/>
</svg>
```

不设变量就是单色，设了可以上下分开上色。在站点里，上组跟着文字颜色，下组跟着主题色，切到红色主题，下组就是红的。默认的中性主题里主题色接近黑白，两组看着是一个颜色。

![「易」从 256px 到 16px：亮色、暗色和双色](/images/blog/logo-design/sizes.png)

缩小测试的时候，28px 以上两组都清楚。到 24px 和 16px，上面三道细杠糊成了一片斜纹，看不出是六根了。不过剪影还在，一眼还是那个形状。在这么小的尺寸上，认得出剪影就算过关，浏览器标签页的图标也只用单色版。

六根杠互不相连，正好可以直接交给我写的 [等轴测标志](/components/isometric-mark/) 组件，每根杠各自挤出成线条 3D，各自遮挡。

![铅笔速写：六根杠挤出成立体](/images/blog/logo-design/isometric-sketch.jpg)

我在组件文档页的 HTML 里看到一行字：「正在加载示例…」。

本站是 Next.js 16 的纯静态导出，页面在构建时就生成好了，没有服务端要等，也没有接口要请求。按理说不该有 loading。

## 我以为首屏是空的

示例是按需加载的客户端组件，HTML 里放的是这行 fallback。我当时认定，JS 下载完之前，用户首屏只能看到这一行字，示例是空的。解法好像也很顺：把示例改成服务端渲染，让 HTML 里直接有内容。

动手前我先做了个原型，想看看问题到底多严重：拦住所有 JS 请求，3 秒不放行，0.8 秒时截图。

## 拦住 JS 之后，示例还在

截图里示例好好地显示着。

原因在 React 的流式输出。服务端先输出 Suspense 的 fallback，真实内容紧跟着藏在一个隐藏节点里：

```html
<div hidden id="S:0">…示例的真实内容…</div>
<script>$RC("B:0", "S:0")</script>
```

（示意，省略了属性。）浏览器解析到这段内联脚本，就把 fallback 换成真实内容，不需要任何外部 JS。我看到的那行字，只是替换前的一瞬间。

原型顺手也测了我原本的方案：在服务端 `await import()` 示例。同一个路由下的示例全被打进一个包，每个组件页的 JS 从约 1.27MB 涨到约 2.4MB。为一个不存在的问题让所有页面多下一倍代码，我直接放弃了。

## 真正在等的四段空白

首屏没事，我就换几个场景再看：点链接跳转、慢网、水合之前。这回找到了四处。站内跳转时，页面已经切过去，示例的代码块还没下完，示例区闪出纯文字。recharts 图表要在浏览器里测量容器，水合前整块空白。慢网下点了链接，预取没命中，页面毫无反应，用户不知道点上没有。区块和模板的 iframe 预览，加载前是一块空白。

四处都卡在同一个时刻：页面已经出来了，内容还没到。

示例区、整页预览和组件缩略图原来各有各的 fallback，我换成同一个骨架：撑满调用方给的尺寸，淡色底，轻微脉冲。它要 150ms 后才出现，内容在这之前到了，就不该让人看到骨架一闪而过。这个延迟用纯 CSS 做，不依赖 JS。系统设置了减少动态效果时，骨架照样延迟出现，只是不脉冲。

图表是四处里最难看的。它不是晚一点出现，而是水合前根本不存在，页面高度也会跟着变。所以服务端先输出一个和最终图表同尺寸的占位，用主题色铺底，画几条虚线网格；水合后真实图表淡入，占位同时淡出。两层叠在一起，占位必须绝对定位，不能参与布局。这一条后来出了问题。

跳转指示只管慢跳转。点击后 200ms 页面还没切过去，它才亮；路径一变就熄，另有 8 秒兜底，防止链接被别的处理器拦下后一直亮着。预取命中的跳转几乎瞬间完成，用户根本看不到它。它最初是页头底边的一条 1px 线，做完发现会和导航当前项下面的指示线叠在一起，分不清哪条在说什么。我把它挪到页头标志右侧，改成三道依次点亮的小斜杠，形状呼应「易」标志的斜杠。

iframe 改成接近视口才挂载，加载中显示同一个骨架。首页「区块与模板」一栏有四个缩小的实时预览，没必要一打开就把四个页面全拉下来。

## 自动检查全绿，验收没过

这件事改的代码不多，时间都花在两次判断上。第一次是动手前的原型，第二次是验收。

我写了个脚本，用 Playwright 挂起所有 JS 请求，检查图表有没有留占位、尺寸对不对。第一版全绿。

然后我让另一个子任务独立验收，不看实现者的汇报，自己实测。它判了不通过，挑出三个阻塞问题。

第一个是骨架根本没有延迟。样式写成了 CSS module，构建配置却把这个文件当全局样式处理，类名丢了，动画没挂上，骨架一出现就是满的。

第二个出在排名图。占位里有一张 1:1 viewBox 的 svg，按宽度撑出一个正方形，把图撑高了 433px；就绪后它只是变透明，还占着位置，空白一直留在页面上。

第三个在列表缩略图。为了让骨架不受缩放影响，缩略图容器在加载态被改成了 `static`，骨架的绝对定位没了参照，高度塌成 0，页面上 25 个看不见的骨架却还在给读屏播报「正在加载…」。

脚本一个都没抓到。第一和第三个是压根没写对应的断言。第二个更隐蔽：CLS 只记录元素跳了多少，这块空白从一开始就在，从来没动过，所以测不出来。

修复都很直接：骨架改成全局类，图表占位改成绝对定位、不再参与布局，缩略图的骨架重新拿回定位参照。我另外补了两条会失败的断言：骨架初始必须透明且动画已挂上；把图表占位临时摘掉，容器高度差必须是 0。同一个脚本还会在放行 JS 之后检查，占位和正常图表的尺寸差是否在 2px 以内。脚本覆盖所有组件页，外加首页、主题页、三个列表页和一个整页预览。

这套做法后来写进了组件书写规范：依赖尺寸测量、canvas、WebGL 或当前时间的内容，水合前必须有同尺寸的占位，占位不占布局；文字内容的服务端输出必须可见，不能为了等挂载把整块文字藏起来。站里的样板是点阵地球，球体出来之前，先放一个和球一样大的径向渐变圆。
